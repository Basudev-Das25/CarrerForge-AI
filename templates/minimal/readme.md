# Minimal Clean Template

A minimalist resume template focusing on content with clean typography and generous whitespace. Ideal for design, writing, and academic roles.

## Features

- Minimal header with name and contact
- Clean section dividers
- Content-forward layout
- ATS-friendly (no tables, no images)
- Generous whitespace for readability
- Automatic page breaking
- Supports multi-page resumes

## Metadata

```yaml
display_name: "Minimal Clean"
description: "Minimalist template focusing on content with minimal decoration"
author: "CareerForge AI"
version: "1.0"
page_size: "us-letter"
font_family: "Georgia"
font_size: 10.5
```

## Theme Customization

Edit `theme.json` to change colors, spacing, and fonts.
