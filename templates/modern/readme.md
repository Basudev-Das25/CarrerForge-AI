# Modern Professional Template

A clean, modern resume template with professional typography and balanced whitespace. Suitable for most industries and roles.

## Features

- Clean header with name and contact info
- Section headings with subtle underline
- Three-column skills grid
- Professional serif/sans-serif hybrid
- ATS-friendly (no tables, no images, no icons)
- Automatic page breaking
- Supports multi-page resumes

## Metadata

display_name: "Modern Professional"
